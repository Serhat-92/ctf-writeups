# Writeup Template

## Room info
Basic details about the target, such as platform, name, category, and difficulty.

## Summary
A short description of the box and the main path I used to solve it.

## Reconnaissance
The first scans and passive checks I run to see what the target exposes.

## Enumeration
A closer look at each open service to find useful information.

## Exploitation
The step that gives me the first shell or the user flag.

## Privilege Escalation
The step that takes me from a low user to root or administrator.

## What I Learned
One or two takeaways I want to remember for the next room.
